# Travello

Sri Lanka hotel booking, transport booking and trip planning.

- `frontend/` Next.js 15 (App Router, TypeScript) + Tailwind CSS v4 (no global.css styles, only Tailwind)
- `backend/`  plain Node.js + Express API

## Run

Terminal 1 (backend, http://localhost:5000)
    cd backend && npm install && npm run dev

Terminal 2 (frontend, http://localhost:3000)
    cd frontend && npm install && npm run dev

Check the API: http://localhost:5000/api/health
